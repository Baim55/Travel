# 🌍 Travel Planning & Booking System

A modern full-stack travel planning and booking platform designed to provide users with a complete and interactive travel experience.

Users can explore destinations, discover tours, create travel plans, make bookings, communicate in real time, and enjoy interactive 3D experiences.

---

## ✨ Features

### 👤 User Features

* User registration and login
* Secure authentication with JWT
* Protected routes
* User profile management
* Explore destinations and tours
* Create travel plans
* Make tour reservations
* Manage bookings
* Add reviews and ratings
* Edit and delete personal reviews
* Real-time chat
* Multi-language support
* Responsive design

### 🗺️ Travel & Exploration

* Explore different destinations
* View detailed tour information
* Select travel dates
* View available tour times
* Create personalized travel plans
* Interactive maps
* 3D model visualization
* Immersive travel experience

### 💳 Payment

* Secure online payment integration with Stripe

### 💬 Real-Time Communication

* Real-time messaging using Socket.io
* Instant communication between users

### 🛠️ Admin Panel

Administrators can:

* Manage users
* Manage destinations
* Manage tours
* Manage bookings
* Manage reviews
* Manage platform content

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/Baim55/Travel.git
cd Travel
```

### 2. Install Frontend Dependencies

```bash
cd front
npm install
```

### 3. Install Backend Dependencies

Open a new terminal:

```bash
cd backend
npm install
```

---

## ▶️ Running the Project

### Start Frontend

```bash
cd front
npm run dev
```

### Start Backend

Open a separate terminal:

```bash
cd backend
npm start
```

> The frontend and backend should be run in separate terminal windows.
